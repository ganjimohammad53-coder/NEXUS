# راهنمای ساخت و انتشار NEXUS 1.0

> **وضعیت:** شماره نسخه‌ی هدف تنظیم شده است؛ تا زمان موفقیت CI ویندوز و smoke test دستی، این بسته انتشار عمومیِ تأییدشده محسوب نمی‌شود.

## پیش‌نیازها
- Windows 10/11 x64
- .NET SDK 8.x سازگار با `global.json`
- دسترسی NuGet برای restore اولیه
- برای نصب‌کننده: Inno Setup 6 و `ISCC.exe`

## ساخت و تست
در PowerShell و پوشه‌ی اصلی پروژه اجرا کنید:

```powershell
dotnet --info
dotnet restore .\NEXUS.sln
dotnet build .\NEXUS.sln -c Release --no-restore
dotnet test .\NEXUS.sln -c Release --no-build
```

## بسته‌بندی
```powershell
.\RELEASE-WINDOWS.ps1
```

اسکریپت در صورت شکست restore/build/test/publish متوقف می‌شود. بسته‌ی portable در `artifacts\NEXUS-1.0-win-x64-portable.zip` ساخته می‌شود. اگر `ISCC.exe` نصب باشد، نصب‌کننده نیز تولید می‌شود.

## داده و حریم خصوصی
داده‌ی محلی در `%LOCALAPPDATA%\NEXUS` قرار دارد. پیش از restore یا حذف دستی داده‌ها، نسخه‌ی پشتیبان تهیه کنید. اجرای plugin/script، AI آنلاین و elevation در این نسخه غیرفعال‌اند. سرویس مجوز درون process، مرز امنیتی مستقل در برابر process compromise نیست.
