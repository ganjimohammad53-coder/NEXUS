# NEXUS UI Redesign 0.4

This package contains an actual shell and dashboard redesign: a larger branded workspace shell, editorial welcome panel, colored shortcut cards for Productivity/Gaming/Network, updated module tiles, and a redesigned quick-action layout. It also fixes the Avalonia tooltip call by using `ToolTip.SetTip`.

## Validation status
- ZIP structure generated from the previous source package.
- Build/run not verified in this environment. Please run `RUN-NEXUS.bat` on Windows 10 with the required .NET 8 SDK.
- This is a UI-focused iteration, not a claim that every module is feature-complete. AI remains intentionally disabled.
